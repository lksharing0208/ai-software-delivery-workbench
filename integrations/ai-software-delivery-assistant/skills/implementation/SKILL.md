# Implementation

## 修改前

1. 阅读 `AGENTS.md`、`CLAUDE.md`（如适用）及相关项目文档。
2. 检查目标分支、工作区状态、目标文件、调用方、被调用方和测试。
3. 明确验收条件、影响范围和回滚方式。
4. 先复用现有实现与依赖；不以猜测补全缺失代码。

## 实施要求

- 最小必要差异，保持接口、状态、异常、事务、日志、命名和编码风格。
- 修改前端/后端/API/数据库时同步检查契约一致性。
- 当前用户身份从服务端认证上下文获取，不信任客户端传入的用户标识。
- 写操作考虑鉴权、输入校验、幂等、并发、事务和审计。
- 不记录密钥、令牌、密码、完整个人信息或敏感请求内容。
- 新增中文注释仅解释复杂业务规则，不添加无意义注释。
- 不删除或弱化测试来掩盖实现问题。

## 完成后

检查完整 Diff、空白错误、无关文件、调试代码和敏感信息。说明实际修改文件及其目的。未运行构建/测试时明确写出“未执行”，不得声称通过。
