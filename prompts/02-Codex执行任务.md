# 提示词 02｜本地实现任务（Codex + DeepSeek）

使用前，确认本地仓库和功能分支正确，并阅读根目录 `AGENTS.md`。

---

请按仓库根目录的 `AGENTS.md` 执行本任务。你是本次唯一主代码修改者，直接基于当前本地项目完成实现与验证。

## 本次任务

【粘贴 GitHub Issue 链接或完整任务单】

## 必须遵循

1. 先执行并查看 `git status --short --branch`，确认仓库、分支与工作区状态。不得覆盖用户已有改动。
2. 先阅读相关源码、调用方、测试和配置；说明实现依据，不要假设不存在的类、方法、字段、API 或命令。
3. 先列出简短计划，再按最小差异修改。不要顺手重构无关模块，不要擅自升级依赖。
4. 按真实业务语义实现，新增或更新有价值的测试；不能通过删除测试、放宽断言或跳过检查来伪造通过。
5. 对配置、权限、数据库、支付、并发、重试和外部调用进行相关风险检查。
6. 不写入真实密钥、不执行未经授权的生产操作、不直接向主分支推送、不强制推送。
7. 完成后执行实际可用的格式/静态检查、构建、相关测试、`git diff --check`，查看 `git diff --stat` 和完整差异。
8. 如果某个命令无法运行，说明真实原因和替代验证方式，不得虚报测试通过。

## 完成后按中文格式汇报

- **完成结果**：逐项对应任务与验收条件。
- **修改文件**：路径、修改内容和理由。
- **实现要点**：关键流程、异常处理、兼容性行为。
- **测试证据**：命令、结果和未覆盖内容。
- **Review 风险**：可能需要独立审查的疑点。
- **发布与回滚**：是否需要迁移、配置、部署步骤和恢复方法。
- **未完成事项**：原因、影响和建议的下一步。

如果现有信息不足以安全实现，不要编造项目事实；先完成不受影响的工作，再明确列出必要缺项。
